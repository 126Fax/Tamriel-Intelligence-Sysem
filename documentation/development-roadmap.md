# Development Roadmap

This is the historical initial-project roadmap, not a description of the
current implementation or setup. Current Rust-primary instructions are in the
[project README](../README.md) and
[Rust implementation guide](../rust-version/README.md).

## Phase 1 – Project Setup
- [ ] Clone the GitHub repository onto the development computer.
- [ ] Check the Python installation.
- [ ] Set up the project environment.
- [ ] Install the required Python libraries.
- [ ] Organise the initial project files.

## Phase 2 – Data Preparation
- [ ] Obtain and inspect the UESP XML dump.
- [ ] Learn how the XML data is organised.
- [ ] Extract individual wiki pages.
- [ ] Clean and organise the extracted text.
- [ ] Prepare data for both AI applications.

## Phase 3 – Top-Down AI Development
- [ ] Design the Lore Assistant's question-handling process.
- [ ] Implement keyword and pattern recognition.
- [ ] Identify different question types.
- [ ] Retrieve relevant information from the prepared data.
- [ ] Generate responses using predefined rules and templates.
- [ ] Test different questions and improve reliability.

## Phase 4 – Bottom-Up AI Development
- [ ] Identify a suitable machine learning problem.
- [ ] Select and prepare training data.
- [ ] Choose an appropriate machine learning algorithm.
- [ ] Train and evaluate the model.
- [ ] Analyse the results.
- [ ] Improve the model where necessary.

## Phase 5 – Testing and Evaluation
- [ ] Test both applications systematically.
- [ ] Record test results.
- [ ] Identify limitations and errors.
- [ ] Compare the two AI approaches.
- [ ] Document possible improvements.

## Phase 6 – Coursework Completion
- [ ] Complete the AI research report.
- [ ] Prepare explanations of both applications.
- [ ] Review code and external resources.
- [ ] Prepare for the practical demonstration and viva.
- [ ] Acknowledge generative AI assistance where required.
