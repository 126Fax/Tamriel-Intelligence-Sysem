# Bottom-Up AI — Inactive development area

The current project milestone is the working **Top-Down AI** question-answering
application. Bottom-Up AI is not currently part of that application and is not
required to run it.

This directory is retained as project work-in-progress rather than deleted.
It contains an earlier prototype, a development scaffold and sample-data
experiments. These files are not connected to the Top-Down AI runtime.

The shared XML ingestion and SQLite code lives under `src/`. It remains
available as the project's source-data preparation pipeline.

When Bottom-Up AI development resumes, update this README to describe the
actual implementation and its tests. Until then, treat the contents of this
directory as experimental and separate from the working Top-Down AI.
