
# Tamriel Intelligence System

## Project Overview

The Tamriel Intelligence System is a Python-based AI project exploring two different approaches to artificial intelligence using information from the Unofficial Elder Scrolls Pages (UESP) Wiki.

The project will consist of two applications:

- **Top-down AI:** A rule-based Natural Language Processing (NLP) application that can understand questions and retrieve information from the Elder Scrolls lore database.
- **Bottom-up AI:** A machine learning application that learns patterns from the lore database and uses them to analyse or classify information.

## Project Objectives

- Explore top-down and bottom-up artificial intelligence techniques.
- Process and organise information from the UESP Wiki XML dump.
- Develop two working Python applications.
- Test and evaluate both applications.
- Compare the strengths and weaknesses of the two AI approaches.
